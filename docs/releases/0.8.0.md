# Macarok 0.8.0

Macarok 0.8.0 brings a Podcasts directory you can explore before subscribing, default sources available from the first launch, and a page for each radio station.

## New

- **Podcasts hub**: the source picker now has a single **Podcasts** entry. **Browse** lists the most popular Apple Podcasts shows for a country and genre, or searches by title or author, sorted by popularity, A–Z, or Z–A. Open a show to read its description and play its latest episodes without subscribing, then choose **Subscribe** to follow it. **Subscribed** shows your shows as an artwork grid with **New**, **In Progress**, and **Downloaded** episode lists. Shows that publish only inside Apple Podcasts have no public feed and cannot be played.
- **Shorter show pages**: a show lists its 10 latest episodes first, with **Show All** for the rest.
- **Default sources**: Internet Radio, Podcasts, Live Music Archive, and LibriVox are present from the first launch. A default source you remove stays removed until you choose **Restore Default Sources** in **Settings › Sources**.
- **Clearer source settings**: **Settings › Sources** groups sources by type (Music, Internet Radio, Podcasts, Internet Archive). Subscribed shows appear as one Podcasts row, with **Manage Subscriptions…**.
- **Radio station page**: the station playing now has its own page with its logo, current title, genres, website, and technical details (format, bitrate) when the stream provides them. Its useless Playing views are hidden.

## Fixes

- **Radio titles**: stations that send an empty title or extra fields no longer show text such as `';StreamUrl='` as the current title.

## Changes

- Subscribed podcasts are no longer listed one by one in the source picker; they are under **Podcasts**. Removing Podcasts in Settings also unsubscribes from every show.

## Keychain after updates

Macarok is signed with a personal certificate, not an Apple Developer ID. After each update, macOS asks once for your login keychain password for each saved item (Last.fm and each server). Choose **Always Allow** so it is not asked again until the next update.

## Download and install

Download `Macarok-0.8.0-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 0.7.3. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

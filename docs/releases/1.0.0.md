# Macarok 1.0.0

Macarok 1.0 is the first stable release: a native macOS music player inspired by Amarok 1.4, with a searchable library across local folders, OpenSubsonic servers, podcasts, Internet radio, and the Internet Archive; rich listening context; and an active playlist grouped by album. This release adds in-app updates and a Settings › About tab, and numbers playlist tracks by their place on the album.

## New features

- **In-app updates**: Macarok checks for updates once a day and from **Check for Updates…** in the Macarok menu and in Settings › About. An available update shows its release notes and installs only on confirmation: Macarok quits, is replaced, and reopens, and the updated app opens without the Gatekeeper prompt. Updates are verified with an EdDSA signature. Turn the daily check off in **Settings › General › Updates**.
- **Settings › About**: the app icon, the full version and build, what Macarok does, its privacy note, and its publisher, with buttons for the bundled licenses, GitHub, and updates. **About Macarok** in the app menu opens it.

## Improvements

- **Album track numbers in the playlist**: tracks under an album header show their number on the album, with the disc for multi-disc albums (2-1), instead of their place in the playlist. Lone tracks and radio stations show no number; a lone track that is playing shows its state over its artwork.

## Fixes

- **A stalled stream no longer runs the cursor ahead**: when VLC kept reporting playback while its clock had stopped, during a stalled network read or decoder, the timeline cursor kept moving, and an error could save a resume point several seconds past what was heard. The cursor now stops on the audio heard until playback moves again, and resume points, saved queue positions, and podcast and Internet Archive progress use the audio heard.

## Download and install

Download `Macarok-1.0.0-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset. This is the last version to install by hand: from 1.0 on, Macarok updates itself.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 0.9.3. Keychain asks once per saved item (Last.fm, the YouTube API key, and each server) for your login keychain password after each update; choose **Always Allow**. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

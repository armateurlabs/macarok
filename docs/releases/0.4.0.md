# Macarok 0.4.0

Macarok 0.4.0 adds similar playlists and dynamic mixes built from listening similarity, and tidies source labels in the active playlist.

## Highlights

- **Similar playlists**: from a track, album, or artist, choose **Create Similar Playlist…** to replace the active playlist with similar tracks from your library. Length is unlimited by default and can be limited. Undo restores the previous playlist.
- **Dynamic mixes**: **Start Similar Mix** announces only the next track, marked with a sparkle. Right-click it and choose **Skip Suggestion** to get another; **Next** also skips the track that was playing. Skipped recordings never return during the mix, and **Restore Skipped Tracks** clears them.
- **Follow**: the mix can follow its seed, the last played track, or both. A banner above the playlist shows the seed, skipped tracks, and Stop Mix.
- Similarity comes from **Last.fm** (when a personal API key is configured in Settings › Scrobbling) and **ListenBrainz** similar artists, which need no account. Suggestions are always tracks already in your library, across every local and OpenSubsonic source. Answers are cached for a week.
- **Playlist sources**: when browsing All Sources, a grouped album names its source once in its header instead of adding a line under each track. **Show Sources**, in the playlist More menus and Settings, hides source labels.

## Privacy

Only the seed artist names and track titles are sent to Last.fm, ListenBrainz, and MusicBrainz. No library contents, listening history, or account information is sent. See [similar playlists and mixes](https://github.com/armateurlabs/macarok/blob/v0.4.0/docs/RECOMMENDATIONS.md).

## Download and install

Download `Macarok-0.4.0-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is ad-hoc signed and is not notarized by Apple; macOS may block the first launch.

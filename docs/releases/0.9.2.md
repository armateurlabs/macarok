# Macarok 0.9.2

Macarok 0.9.2 adds whole-album selection to the playlist and fixes two playback issues: a paused timeline cursor pulled back by a stale clock sample, and YouTube videos that could not go fullscreen.

## New features

- **Whole-album selection in the playlist**: clicking an album header in the active playlist selects every track of that album; ⌘-click adds another album to the selection, and Delete removes all selected tracks. Undo and redo restore the selection as it was. While every track of an album is selected, the header row paints the same selection band as native rows, so the album reads as one selected block.

## Fixes

- **YouTube videos go fullscreen**: the player's fullscreen button now works as it does in a browser — the video moves to its own fullscreen screen and returns to the tab at exactly the position it was at. Before, the button did nothing useful: Macarok's own window entered fullscreen on top of WebKit's fullscreen presentation, and WebKit collapsed the video's viewport to nothing inside SwiftUI-hosted web views. The web views are now hosted in a plain container that survives that round trip.
- **The paused cursor no longer jumps back**: right after pausing, VLC sometimes reports a stale, pre-seek position; the paused timeline cursor now keeps its accepted position instead of rewinding to the stale sample.

## Download and install

Download `Macarok-0.9.2-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 0.9.1. Keychain asks once per saved item (Last.fm, the YouTube API key, and each server) for your login keychain password after each update; choose **Always Allow**. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

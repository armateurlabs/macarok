# Macarok 1.0.1

Macarok 1.0.1 gives the menu bar mini player its own icon.

## Improvements

- **The Macarok wolf in the menu bar**: the menu bar item now shows the app icon's wolf, holding its apple, instead of a generic music note. It is a monochrome icon that follows the menu bar's light or dark appearance and its highlight, like the system icons. Turn the menu bar item on in **Settings › General › Menu Bar**.

## Download and install

If Macarok 1.0.0 is installed, choose **Check for Updates…** in the Macarok menu, or wait for the daily check, and install the update from there.

Otherwise, download `Macarok-1.0.1-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 1.0.0. Keychain asks once per saved item (Last.fm, the YouTube API key, and each server) for your login keychain password after each update; choose **Always Allow**. It is not notarized by Apple: macOS blocks the first launch of a downloaded version, not an in-app update. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

# Macarok 0.9.1

Macarok 0.9.1 keeps the timeline cursor steady when Bluetooth headphones change their audio latency.

## Fixes

- **Steady timeline over Bluetooth**: Bluetooth headphones periodically renegotiate their output latency, and VLC then reports a position that jumps forward by that latency and snaps back, while the audio you hear keeps playing uninterrupted. The cursor now follows a steady line through those steps: it holds through a latency jump, settles onto the clock when it really moves, and freezes with the audio when playback stalls instead of running ahead of it. Resume positions and CUE track boundaries follow the same steady cursor.
- **Cursor follows wired output too**: speakers and wired devices have a steady output delay, and the clock legitimately leads real time by it. The cursor now follows that lead instead of fighting it, so it no longer drifts ahead of the audio and jumps back.

## Download and install

Download `Macarok-0.9.1-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 0.9.0. Keychain asks once per saved item (Last.fm, the YouTube API key, and each server) for your login keychain password after each update; choose **Always Allow**. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

# Macarok 0.7.2

Macarok 0.7.2 keeps sources up to date on its own, gives empty panels one consistent look, and fixes a first track that could fail to play.

## Highlights

- **Sources refresh in the background**: a few seconds after launch, Macarok rescans your music folders to pick up changes made while it was closed; only new or modified files are read. Every hour, it asks each OpenSubsonic server (such as Navidrome) whether its library changed, and imports the catalog again only when it did. Your cached library stays fully usable meanwhile and is updated once, at the end, only if something changed. An unreachable server or folder is reported in the status bar instead of an alert.
- **Consistent empty panels**: empty, loading, and error messages share one background and text size and line up across the library, center, and playlist panels. The Wikipedia bar and the metadata editors' Cancel/Save row line up with the other panel footers.
- **Home after clearing the playlist**: emptying the playlist while Playing follows playback now shows Home rather than an empty Playing view.
- **Refresh progress in one place**: refresh progress appears only in the status bar, no longer repeated and truncated in the library footer.

## Fixes

- **First track plays reliably**: VLC no longer looks up saved internet passwords in the Keychain when it opens a stream. A Keychain prompt for your server's address could stop the first Navidrome track of a session from playing until it was clicked again.

## Download and install

Download `Macarok-0.7.2-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 0.7.1. Keychain asks once per saved item (Last.fm and each server) for your login keychain password after each update; choose **Always Allow**. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

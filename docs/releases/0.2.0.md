# Macarok 0.2.0

Macarok 0.2.0 adds unified library browsing, synchronized lyrics, more sources, and an optional menu bar mini player, with a new wolf-and-apple icon.

## Highlights

- Optional **All Sources** browsing combines search, Home rankings, and library views while preserving each source's albums, tracks, credentials, and history.
- Centered **Home / Playing** navigation, focused Home filters, Wikipedia, and configurable automatic navigation to Playing. Metadata and artwork drafts keep their original targets during playback.
- Synchronized lyrics from local files, OpenSubsonic, and LRCLIB, with manual search/corrections, timed highlighting, and explicit local-file export.
- Native playlist Undo/Redo, Add After Current Track actions, complete artist/album double-click selections, and library shuffle that appends to an existing queue.
- Optional **Last.fm scrobbling** with personal API credentials, browser authorization, source exclusions, and a persistent submission queue.
- Internet radio with manual URLs, Radio Browser discovery, favorites, and live metadata. Podcast discovery, newest-first episodes, explicit offline downloads, and Reveal in Finder.
- Shared album metadata editing preserves individual track titles, numbering, and CUE boundaries. Recording identification follows moved local bookmarks and can use partial fingerprints with a separate decoding warning; lookup errors and missing recording metadata remain distinct.
- A menu bar mini player with artwork, matching single-row panel footers, aligned album tiles, and refined Light/Dark controls.

## Playback and reliability

- Improved remote FLAC/Ogg seeking, click/drag timeline input, held-arrow seeking, and start-position selection for stopped tracks.
- Prepared next-track playback, bounded stream buffering, cached local scans, and targeted background updates reduce interruptions during library work. Playback diagnostics report stalls without silently skipping the entry.
- Fixed a VLC notification lifetime crash. Clear Playlist retains active playback, but empties paused/stopped queues; native Undo can restore the queue without autoplay.

## Download and install

Download `Macarok-0.2.0-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is ad-hoc signed and is not notarized by Apple; macOS may block the first launch.

## License and scope

Macarok is released under the MIT license. Bundled dependencies retain their own licenses and notices, included in the application.

This remains an early release. Gapless playback is optional; crossfade, HLS radio, dedicated commercial-service playback, and cloud-storage integration are outside this release. Bandcamp uses the existing OpenSubsonic connector. See [verification and remaining manual checks](https://github.com/armateurlabs/macarok/blob/v0.2.0/docs/VERIFICATION.md).

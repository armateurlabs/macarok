# Macarok 0.7.3

Macarok 0.7.3 keeps the library steady while a server refreshes, reducing the risk of a crash seen during a refresh with an active search.

## Fixes

- **Steadier refresh**: refreshing a server that is already in your library no longer rebuilds the library list every few hundred milliseconds. The cached catalog stays as it is until the refresh ends, then updates once if something changed; a library search updates at the same time. Macarok crashed in the system's list handling during such a refresh, with a search active, while the server was rescanning its files. Adding a new server still shows its albums as they arrive.
- **Better diagnostics**: when a track cannot be prepared for playback, the diagnostics log now records the type of error (never its message), so a failure hidden behind a later alert can be identified.

## Keychain after updates

Macarok is signed with a personal certificate, not an Apple Developer ID. After each update, macOS asks once for your login keychain password for each saved item (Last.fm and each server). Choose **Always Allow** so it is not asked again until the next update.

## Download and install

Download `Macarok-0.7.3-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so privacy approvals carry over from 0.7.2. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

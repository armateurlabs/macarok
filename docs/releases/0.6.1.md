# Macarok 0.6.1

Macarok 0.6.1 keeps playing through network interruptions and is signed with a stable certificate.

## Fixes

- **No more skipped tracks on a dropped connection**: a network drop, server restart, or proxy timeout used to look like the end of the file, so a track from Navidrome or another OpenSubsonic server could jump to the next one partway through. Macarok now reconnects and continues from the first missing byte when it can, and otherwise plays the same track again from where it stopped (up to three times) without counting the play twice. After repeated drops it stops on that track with an explanation, and **Play** continues from the same position. Local files and CUE tracks are unaffected.

## Signing

- Releases are signed with the Armateur Labs certificate instead of an ad-hoc signature. The app keeps the same identity across updates, so Keychain access to saved server credentials and privacy permissions no longer need to be approved again after each update. The first launch of this version asks once more; choose **Always Allow**.
- The certificate is self-signed and the app is not notarized by Apple: macOS still blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

## Download and install

Download `Macarok-0.6.1-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later.

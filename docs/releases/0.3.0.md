# Macarok 0.3.0

Macarok 0.3.0 makes the library and the active playlist easier to organize: sortable library lists, album groups in the playlist, native selection, drag and drop, and more forgiving automatic lyrics.

## Highlights

- **Library sorting**: one arrow in each library list switches between ascending and descending order. Artists, albums, years, folders, and tags remember their own order; years are newest first by default.
- **Album groups in the playlist**, enabled by default: consecutive tracks from the same album share a header with artwork, artist, year, track count, and duration. The option is available in the playlist menus and in Settings.
- **Native library selection**: the active artist, album, track, or folder uses the standard blue selection. Double-click plays the selection.
- **Drag and drop**: drag artists, albums, tracks, or folders from the library into the playlist, at any position. Playlist rows can be reordered by grabbing them anywhere, and insertions and moves support Undo.
- Library tabs use the same bold typography as the panel titles.

## Lyrics

- Automatic LRCLIB lookups ignore placeholder metadata such as "[Unknown Album]", retry without the album, and then search with simplified titles (no track numbers, remaster or version suffixes, or featured artists) and the primary artist.
- A lenient match is accepted only when the artist matches, the duration is within three seconds, and it is not a different edition such as a live, acoustic, demo, or remix take. Synced lyrics are preferred.
- Find Lyrics leaves placeholder fields blank.

## Download and install

Download `Macarok-0.3.0-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is ad-hoc signed and is not notarized by Apple; macOS may block the first launch.

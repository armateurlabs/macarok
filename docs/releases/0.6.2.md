# Macarok 0.6.2

Macarok 0.6.2 redesigns the playback bar.

## Highlights

- **Playback bar**: Previous, Play/Pause, and Next stay at the leading edge and the volume at the trailing edge. Between them, one boxed unit uses the available width: the artwork, the title with “Artist — Album” below it (the current chapter for a podcast, the station for radio), then the timeline with elapsed time and duration, level with the volume. Long titles are truncated instead of pushing the timeline aside.
- **Artwork**: click the artwork to see it enlarged at full resolution. Its context menu offers **Choose Artwork…** for music and **Show Current Track**.
- README previews are refreshed with the new playback bar.

## Download and install

Download `Macarok-0.6.2-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so Keychain and privacy approvals carry over from 0.6.1. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

# Macarok 0.7.0

Macarok 0.7.0 gives every context panel the same layout and adds artist pictures.

## Highlights

- **Play Next**: tracks, albums, artists, and folders can be added right after the current track from their context panel, next to **Add to Playlist** and **Shuffle**. Play Next can be undone like any other playlist edit.
- **Consistent context panels**: track, album, artist, and folder panels share one layout. The square artwork, details, and the **Add to Playlist · Play Next · Shuffle** buttons sit at the same place and size on every panel. A single track has no Shuffle button.
- **Artist pictures**: each artist has a square picture shared by all of their albums. A music note is shown until Macarok finds a picture on Last.fm (when connected in Settings) or Wikipedia and saves it in the library. Right-click the picture to choose an image file, search the web, or find a picture automatically again. A picture you choose is never replaced automatically.
- **Smoother artwork**: switching between track, album, and artist panels no longer flashes a placeholder or the previous item's picture.

## Download and install

Download `Macarok-0.7.0-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so Keychain and privacy approvals carry over from 0.6.2. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

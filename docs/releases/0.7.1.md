# Macarok 0.7.1

Macarok 0.7.1 fixes a main window that could disappear while music kept playing, and a library search that reloaded on every click.

## Fixes

- **Main window always comes back**: **Show Window** in the menu bar mini player and the global **Show Macarok** shortcut now restore a window minimized to the Dock instead of opening a second one. Clicking the Dock icon reopens the window after it was closed. Previously the window could stay hidden until Macarok was restarted.
- **Steady search results**: with a library search active, selecting a result or clicking back into the search field no longer clears and reloads the list.
- **Playlist undo**: the playlist undo handler now joins the main window's responder chain as intended.

## Download and install

Download `Macarok-0.7.1-arm64.dmg`, open it, and drag Macarok to Applications. A SHA-256 checksum is provided as a separate release asset.

Requires an Apple Silicon Mac and macOS 14 or later. The application is signed with the Armateur Labs certificate, so Keychain and privacy approvals carry over from 0.7.0. It is not notarized by Apple: macOS blocks the first launch of a downloaded version. Approve it in **System Settings › Privacy & Security › Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Macarok.app` after copying the app.

# Macarok 0.1.0

The first public release of Macarok, a native macOS music player inspired by Amarok.

## Included

- A resizable three-panel interface with System, Light, and Dark appearances.
- Separate local-file, OpenSubsonic/Navidrome, and podcast libraries, indexed in SQLite.
- Artist, album, year, folder, and tag views, grouped search, and listening history.
- VLC 4 audio playback, CUE tracks, repeat, shuffle, Mac media keys, and custom shortcuts.
- An active playlist with Play Now actions and clearing that preserves the current track.
- Metadata editing, artwork retrieval and embedding, MusicBrainz matching, and optional Chromaprint identification.
- Progressive catalog loading and background library preparation for large collections.

## Download and install

Download `Macarok-0.1.0-arm64.dmg`, open it, and drag Macarok to Applications.

Requires an Apple Silicon Mac and macOS 14 or later. This initial build is ad-hoc signed and is not notarized by Apple; macOS may block the first launch. The DMG includes a SHA-256 checksum file as a separate release asset.

## License and scope

Macarok is released under the MIT license. Bundled dependencies retain their own licenses and notices, included in the application.

This is an early release. Gapless playback is optional; crossfade, merged source libraries, commercial streaming services, and cloud-storage integration are outside this iteration.
